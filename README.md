# 💌 Приглашение на свидание для Николь (SPA)

Интерактивный одностраничный сайт-приглашение на свидание в эстетике **«Old Money / Quiet Luxury»** (Ralph Lauren, Loro Piana).

---

## ✨ Особенности и эстетика

- **Эстетика «Тихой роскоши»**:
  - Палитра: благородная слоновая кость (`#F4F0E8`), античное золото (`#C5A880`), матовое серебро (`#D1D5DB`) и угольно-графитовый текст.
  - Тактильная текстура винтажной бумаги с микрозерном, деликатные двойные рамки и вензели.
  - Шрифты: *Playfair Display*, *Cormorant Garamond*, *Cinzel*, *Montserrat*, *Pinyon Script* и каллиграфический *Marck Script*.
- **4 интерактивных этапа**:
  1. **3D Конверт**: парящий конверт с серебряной сургучной печатью-сердцем, каллиграфической подписью «For Nikol», откидыванием клапана и кинематографичным зумом («fly-in»).
  2. **10 активностей**: изысканная сетка карточек с микро-описаниями, модальным фокусом и сценариями подтверждения:
     - 1. Пирогов
     - 2. Stand up
     - 3. Вечір джазу
     - 4. Скалолазанье
     - 5. Стрельба из лука *(кнопка перехода к еде)*
     - 6. Біг Тенис *(кнопка перехода к еде)*
     - 7. Хоррор комната (квест) *(кнопка перехода к еде)*
     - 8. Приют для сабачек *(кнопка перехода к еде)*
     - 9. Стрельбище *(кнопка перехода к еде)*
     - 10. Вкусно покушать, кино и 🔞 *(с полем для особых пожеланий)*
  3. **Выбор гастрономической локации**:
     - «Свой вариант» с текстовым вводом
     - Категория «Basic»: McDonald’s, ChinChin, Японський привіт, Селям, Баранчик, Thegentelman
  4. **Финальный экран триумфа**:
     - Каллиграфическая надпись: *«Приглашение на свидание принято! Люблю тебя! Моя Николь»*
     - Сводный билет с выбранными параметрами свидания
     - Золотисто-серебряный салют на Canvas (палитра шампанского и платины без детских пестрых цветов)
- **Telegram Bot API**:
  - Мгновенная отправка ответа Николь прямо в Telegram с указанием активности, ресторана, пожеланий и точного времени.
  - Токен бота и Chat ID уже интегрированы в `app.js`.
- **100% мобильная адаптивность**: безупречный вид на iPhone (Safari / Chrome) и любых экранах.

## 🚀 Публикация на GitHub Pages (за 1 минуту)

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `nikol-date`).
2. В терминале в папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Date invitation for Nikol"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_НИК>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
3. На GitHub перейдите в **Settings** &rarr; **Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
5. Через 1-2 минуты ваш сайт будет доступен по ссылке:
   `https://<ВАШ_НИК>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`
